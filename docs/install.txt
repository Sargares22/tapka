# Install Tapka for the person, or add their programs to it

Tapka is a touch panel for Windows 11: a capsule of big keys at a screen edge that open programs
and send keyboard shortcuts, with small meters under the keys.

Talk to the person in their language. Follow the tapka-setup skill: it checks the machine,
installs Tapka with the person's help, finds their programs, asks one question with a short list,
adds keys and meters to the settings file, and verifies the result. Later, when the person names
more programs, the same skill adds them.

If you can install skills, download every file below into your skills directory, keeping the
paths inside tapka-setup. Claude Code uses ~/.claude/skills/tapka-setup; Codex uses
~/.agents/skills/tapka-setup. Then read SKILL.md and follow it.

Otherwise, fetch SKILL.md and follow its steps. Read each reference when its step calls for it.
