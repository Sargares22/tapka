# Tapka — for coding agents

Tapka is a touch panel for Windows 11: a capsule of big keys at the screen edge that starts
programs and sends keyboard shortcuts. This file only points; the content is in `docs/`.

- What it does for the user: `README.md`.
- The words, where things live and what leads to what: `docs/map.md`.
- What breaks when touched carelessly: `docs/traps.md`.
- Commands, recipes and what holds everywhere: `docs/working.md`.
- What changed in each version: `CHANGELOG.md`.

Read the three documents in `docs/` before changing code.
