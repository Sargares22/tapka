# Встроенные значки

Файлы в этой папке вшиты в бинарник и подключаются по имени из файла настроек: `"icon": "snip"`
берёт `snip.svg`. Все значки монохромные, `currentColor`, viewBox 24×24, линия 1.8.

Все значки нарисованы для проекта Tapka и распространяются на условиях его лицензии (WTFPL).
Фирменных знаков чужих продуктов в наборе нет: значок программы панель берёт из самой программы
на машине пользователя.

| Файл | Для чего |
|---|---|
| snip.svg | Снимок области экрана |
| paste.svg | Вставить |
| copy.svg | Копировать |
| undo.svg | Отменить |
| mic.svg | Голосовой ввод, диктовка |
| tasks.svg | Представление задач |
| desktop.svg | Показать рабочий стол |
| folder.svg | Проводник, папка, файл |
| gear.svg | Параметры |
| keyboard.svg | Экранная клавиатура, сочетание клавиш |
| terminal.svg | Терминал, команды |
| chat.svg | Чат, мессенджер |
| browser.svg | Сайт, любой адрес |

Свой значок: положить PNG или SVG в подпапку `icons` папки данных панели и указать имя файла.
